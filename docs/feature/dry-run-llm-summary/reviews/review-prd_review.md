### 🚨 MUST

#### 1. PRDファイルに実行ログが混入している

**該当箇所**: ファイル冒頭〜`---` 区切りまでの全内容（`[DRY-RUN] ワークフロー: my-workflow...` および `# ワークフロー実行コンテキスト（前ステップの成果）` セクション）

PRD本文にツールの実行ログとワークフロー実行コンテキストがそのまま転記されています。これらはシステムの内部出力であり、PRDに記載すべき内容ではありません。PRDには要件・仕様のみを記述してください。該当箇所をすべて削除し、`## 1. エグゼクティブサマリー` から始まる形式に修正してください。

---

#### 2. 未設定時の表示形式が矛盾している

**該当箇所**:
- セクション5（コア機能）P0行: 「未設定時は `(default)` または `(unset)` と表示する」
- セクション5 P1行・セクション9（受け入れ条件）: `(unset)` と表示する
- セクション6 シナリオ1のコード例: `(unset → default が使用されます)` と表示されている

3箇所で表示文字列が異なっており、開発者がどれを実装すべきか判断できません。仕様として1つに統一し、全セクションで統一表記してください。
